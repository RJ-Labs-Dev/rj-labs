# rj-labs.com

Static website for RJ Labs, Flagstaff, Arizona: practical AI automation for owner operated small businesses. Plain HTML, CSS, and JavaScript, hosted on GitHub Pages from the `main` branch (custom domain in `CNAME`).

- `index.html` the landing page
- `styles.css` design system (dark, WCAG AA contrast)
- `app.js` mobile menu, old anchor redirects, example animation, contact form
- `privacy.html` privacy notice for the contact form
- `404.html` not found page

Lead capture: the contact form posts to the RJ Labs Google Form ("RJ Labs contact", owned by info@rj-labs.com). Responses are in that form's Responses tab. If the form's questions are ever recreated, update the `entry.` IDs in `app.js`.
