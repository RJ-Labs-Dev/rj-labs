# rj-labs.com

Static website for RJ Labs, Flagstaff, Arizona. Plain HTML, CSS, and JavaScript, hosted on GitHub Pages.

- `index.html` the whole site
- `styles.css` design system (dark, WCAG AA contrast)
- `app.js` the free presence check. Runs only in the visitor's browser and sends nothing anywhere.
- `assets/portfolio/` real screenshots of live client sites
